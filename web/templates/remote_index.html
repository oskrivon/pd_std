Setup Instructions

1. On the local machine (with Claude Code):

python -m studio.core.local_worker --workspace "./workspace" --url ws://YOUR_SERVER:8081/ws/worker

2. Access this server from any browser to review assets.

3. When a worker is connected, you can:

  • Scan projects for assets
  • View generated images
  • Submit feedback
  • Request regeneration
  • Approve final assets
