## Решения

### Style Transfer Pipeline — 2026-03-03
**Контекст:** Нужно стилизовать скриншоты игры в стиле Deceiver (Loop Hero)
**Протестированы:**
1. `gemini-pro` — лучший, сохраняет layout, понимает промпты
2. `flux-lora-edit` — хорош с LoRA, требует настройки
3. `reve-remix` — альтернатива, хорошо сохраняет композицию
4. `qwen-edit` — надёжный baseline
5. `flux-kontext` — не подходит (объединяет изображения)
6. `flux-edit` — не подходит (генерирует новое)
**Решение:** Комбинированный пайплайн: Gemini Pro → Алгоритмическая обработка → UI маска
**Почему:** Gemini Pro сохраняет композицию, алгоритм добавляет палитру Deceiver, маска защищает UI
**Инструмент:** `tools/style_transfer/pipeline.py --ai-model gemini-pro --ui-mask backpack_hero_minimal`

### AI модели для UI генерации — 2026-03-02
**Контекст:** Нужно генерировать концепты UI/интерфейсов для игр
**Протестированы:**
1. `flux/schnell` — быстрый, абстрактный, для итераций
2. `flux-pro` — детальный, понимает структуру, читаемый текст
3. `dall-e-3` — не работает через aimlapi
4. Midjourney — художественный, но нет API
5. Ideogram — лучший для текста (90% точность)
**Решение:** `flux-pro` для финальных UI концептов, `flux/schnell` для быстрых набросков
**Почему:** flux-pro понимает layout структуру, генерирует читаемые надписи, хорошо работает с pixel art

### Workflow генерации UI концептов — 2026-03-02
**Контекст:** Нужен повторяемый процесс генерации UI
**Workflow:**
1. Собрать референсы: UI стиль (Into the Breach) + компоновка (текущий проект)
2. Определить зоны экрана (backpack, field, room)
3. Задать цветовую схему (dark theme, cyan/orange accents)
4. Промпт на английском с детальным описанием каждой зоны
5. Генерация 3+ вариантов через flux-pro
6. Итерации с уточнением промпта
**Инструмент:** `tools/concept_gen/generator.py`

### Архитектура адаптеров — 2025-02-21
**Контекст:** Нужен единый интерфейс для разных движков (LÖVE, Unreal, потенциально Godot)
**Варианты:**
1. Отдельные скрипты для каждого движка
2. Unified adapter с ABC интерфейсом
3. Plugin система
**Решение:** Unified adapter (вариант 2)
**Почему:** Проще реализовать, достаточно гибко для 2-3 движков, можно расширить до plugin системы позже

### Переиспользование babylon/MCP — 2025-02-21
**Контекст:** В babylon уже есть 28 MCP tools, vision pipeline, rebuild
**Варианты:**
1. Скопировать код в studio
2. Импортировать как модуль
3. Обернуть в UnrealAdapter
**Решение:** Обернуть в UnrealAdapter (вариант 3)
**Почему:** Минимум дублирования, babylon продолжает развиваться независимо

### Token Economy Strategy — 2025-02-21
**Контекст:** Нужно эффективно использовать токены
**Варианты:**
1. Всегда использовать Opus
2. Всегда использовать Sonnet
3. Model tiering по типу задачи
**Решение:** Model tiering (вариант 3)
**Почему:**
- Opus ($15/1M) для архитектуры и планирования
- Sonnet ($3/1M) для кода и дебага
- Haiku ($0.25/1M) для форматирования и boilerplate

### Asset Generation Pipeline — 2025-02-21
**Контекст:** Нужно генерировать арт для прототипов
**Варианты:**
1. Только DALL-E
2. Только процедурная генерация
3. Комбинация + плейсхолдеры
**Решение:** Комбинация (вариант 3)
**Почему:** DALL-E для уникального (персонажи), процедурка для паттернов (тайлы), плейсхолдеры для WIP
